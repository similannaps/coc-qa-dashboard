## 📌 ภาพรวม

ระบบอ่านข้อมูลผลงานตีพิมพ์จาก **Google Sheets** แล้วแสดงเป็นกราฟบนหน้าเว็บ ผู้ใช้เลือกช่วงเวลา (ปีและเดือน) อาจารย์ หลักสูตร และฐานข้อมูล (Indexing) ได้เอง เปรียบเทียบผลงานของอาจารย์หลายคนได้ ส่งออกข้อมูลสรุปเป็น CSV หรือ PDF และเพิ่มข้อมูลใหม่ผ่านหน้าเว็บได้

## ✨ ฟีเจอร์

- **ตัวกรอง 5 แบบ:** ช่วงปีและเดือน, ชื่ออาจารย์, หลักสูตร, ฐานข้อมูล (Indexing) พร้อมปุ่มค้นหาและล้าง
- **การ์ดสรุป 4 ใบ:** ผลงานทั้งหมด, จำนวนอาจารย์, เฉลี่ยต่อคน, ปีหรือเดือนที่มีผลงานมากสุด
- **กราฟ 4 ชนิด:** แท่งรายปี/รายเดือน (แยกกลุ่มได้), โดนัทสัดส่วนประเภทผลงาน, แท่งแยกตามหลักสูตร, แท่งแนวนอน Top 10 อาจารย์ ทุกกราฟแสดงตัวเลขบนกราฟ
- **เปรียบเทียบอาจารย์:** เลือกกี่คนก็ได้ แสดงเป็นกราฟแท่งเทียบกันตามช่วงเวลา
- **ส่งออกข้อมูล:** สรุปเป็น CSV, รายการผลงานเป็น CSV (ตามตัวกรองปัจจุบัน), บันทึกเป็น PDF (ผ่านหน้าต่างพิมพ์ เลือก Save as PDF และติ๊กพิมพ์กราฟิกพื้นหลัง)
- **เพิ่มข้อมูลผ่านเว็บ:** ฟอร์มในปุ่ม "จัดการข้อมูล" ป้องกันด้วยรหัสผู้ดูแล
- **แปลงปี พ.ศ. เป็น ค.ศ. อัตโนมัติ** และรองรับหน้าจอหลายขนาด
- **สีประจำวิทยาลัย:** เทอร์คอยซ์ `#33c0ca` และแดงอิฐ `#b52324`

## 🏗️ สถาปัตยกรรมและความปลอดภัย

```
อ่านข้อมูล:
ผู้ใช้ → index.html (Vercel) → /api/get-data → Google Sheets (เผยแพร่เป็น CSV)

เพิ่มข้อมูล:
ผู้ใช้ → ฟอร์ม + รหัสผู้ดูแล → /api/add-data → Google Apps Script → Google Sheets
```

**หลักการออกแบบ**
- หน้าเว็บเรียกเฉพาะ `/api/get-data` และ `/api/add-data` ซึ่งอยู่ในโดเมนของโปรเจกต์เอง
- ลิงก์ข้อมูล รหัสผู้ดูแล และโทเคน เก็บใน **Environment Variables** บน Vercel จึงไม่อยู่ในซอร์สโค้ดและไม่ถูกเผยแพร่บน GitHub
- ฟังก์ชันไม่แสดงลิงก์ข้อมูลในข้อความ error หรือ log
- แคชผลลัพธ์ 5 นาทีที่ Edge ของ Vercel ลดการเรียก Google และโหลดเร็วขึ้น
- `/api/get-data` รับเฉพาะ `GET` และ `/api/add-data` รับเฉพาะ `POST`
- การเพิ่มข้อมูลตรวจรหัสผู้ดูแลด้วยการเทียบแบบ constant-time ตรวจรูปแบบข้อมูล (จำกัด 500 แถวต่อครั้ง) และกัน formula injection ก่อนเขียนลงชีต
- ไฟล์ `.gitignore` กันไม่ให้ไฟล์ `.env` ถูกอัปโดยไม่ตั้งใจ

> **ข้อควรทราบ:** วิธีนี้ซ่อน URL ของแหล่งข้อมูล แต่ข้อมูลที่แสดงบนกราฟยังเปิดดูได้ผ่าน `/api/get-data` เพราะหน้าเว็บต้องใช้ข้อมูลชุดเดียวกัน รหัสผู้ดูแลเป็นรหัสเดียวร่วมกัน หากนำไปใช้จริงควรเพิ่มระบบล็อกอินของหน่วยงาน

## ⚙️ Environment Variables

| ชื่อตัวแปร | ใช้ทำอะไร | จำเป็น |
|---|---|:---:|
| `GOOGLE_SHEET_API_URL` | ลิงก์ CSV ของ Google Sheets ที่เผยแพร่ (ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ → CSV) | ✅ |
| `ADMIN_KEY` | รหัสผู้ดูแลสำหรับเพิ่มข้อมูลผ่านเว็บ | สำหรับเพิ่มข้อมูล |
| `SHEET_WRITE_URL` | URL ของ Apps Script Web App (ลงท้ายด้วย `/exec`) | สำหรับเพิ่มข้อมูล |
| `SHEET_WRITE_TOKEN` | ข้อความสุ่มยาวๆ ให้ตรงกับ `TOKEN` ใน Apps Script | สำหรับเพิ่มข้อมูล |

หากยังไม่ตั้งค่าสามตัวสุดท้าย ฟอร์มเพิ่มข้อมูลจะเพิ่มข้อมูลชั่วคราวเฉพาะหน้าที่เปิดอยู่

### ตั้งค่าบน Vercel
1. เข้า https://vercel.com แล้วกด **Add New → Project** เลือก repo นี้จาก GitHub (Framework Preset: **Other**)
2. เปิดส่วน **Environment Variables** ใส่ตัวแปรตามตารางด้านบน แล้วกด **Add** ทีละตัว
3. กด **Deploy**
4. หากแก้ค่าภายหลัง ไปที่ **Settings → Environment Variables** แล้วกด **Redeploy** เพื่อให้ค่าใหม่มีผล

### ตั้งค่าการเพิ่มข้อมูลลงชีต
1. เปิดชีตหลัก → **ส่วนขยาย → Apps Script** แล้ววางโค้ดจาก `apps-script/Code.gs`
2. ที่ **Project Settings → Script Properties** เพิ่ม `TOKEN` (ข้อความสุ่มยาวๆ) และ `SHEET_ID` (ID ของชีต)
3. กด **Deploy → New deployment → Web app** ตั้ง Execute as: **Me** และ Who has access: **Anyone** แล้วคัดลอก URL (ลงท้าย `/exec`)
4. นำ URL ไปใส่ `SHEET_WRITE_URL` และค่า `TOKEN` เดียวกันไปใส่ `SHEET_WRITE_TOKEN` บน Vercel แล้ว Redeploy

### ทดสอบในเครื่อง
```bash
npm install -g vercel
cp .env.example .env.local     # แล้วแก้ค่าใน .env.local
vercel dev
```
เปิด http://localhost:3000

## 📝 วิธีอัปเดตข้อมูล

- **แก้ในชีตโดยตรง:** เพิ่ม แก้ หรือลบแถว เว็บแสดงข้อมูลใหม่ภายในประมาณ 5–10 นาที (รอการเผยแพร่ของ Google และแคชของเว็บ) แล้วรีเฟรช
- **เพิ่มผ่านเว็บ:** กด **จัดการข้อมูล** กรอกปี เดือน ชื่ออาจารย์ หลักสูตร ประเภทผลงาน ฐานข้อมูล ใส่รหัสผู้ดูแล แล้วกดบันทึก
- ห้ามเปลี่ยนชื่อหัวคอลัมน์ในชีต และต้องคงการเผยแพร่ชีตไปยังเว็บไว้
