## 📌 เกี่ยวกับเว็บไซต์

**CoC QA Dashboard** เป็นเว็บไซต์สำหรับแสดงผลและวิเคราะห์ข้อมูลผลงานทางวิชาการของอาจารย์วิทยาลัยการคอมพิวเตอร์ ผ่านการนำเสนอข้อมูลในรูปแบบ Dashboard ที่เข้าใจง่าย

เว็บไซต์เชื่อมต่อข้อมูลกับ **Google Sheets** และนำข้อมูลมาประมวลผลเป็นกราฟ ตาราง และสถิติสรุป เพื่อช่วยให้ผู้ใช้งานสามารถสำรวจแนวโน้มผลงานทางวิชาการ เปรียบเทียบข้อมูลในแต่ละช่วงเวลา และวิเคราะห์ผลงานตามอาจารย์ หลักสูตร ประเภทผลงาน และฐานข้อมูลที่ตีพิมพ์ได้

นอกจากนี้ เว็บไซต์ยังมีระบบจัดการข้อมูลสำหรับผู้ดูแล เพื่อช่วยให้การเพิ่ม แก้ไข และจัดการรายการผลงานทางวิชาการทำได้สะดวกยิ่งขึ้น

### 🎯 วัตถุประสงค์ของเว็บไซต์

1. นำเสนอข้อมูลผลงานทางวิชาการของอาจารย์ในรูปแบบที่เข้าใจง่าย
2. ช่วยวิเคราะห์และเปรียบเทียบจำนวนผลงานในแต่ละปีและเดือน
3. แสดงสัดส่วนผลงานตามประเภท หลักสูตร และอาจารย์
4. สนับสนุนการค้นหาและกรองข้อมูลตามเงื่อนไขที่ผู้ใช้สนใจ
5. อำนวยความสะดวกในการส่งออกข้อมูลและบริหารจัดการฐานข้อมูลผลงานทางวิชาการ

## ✨ ความสามารถหลักของเว็บไซต์

### 🔎 1. ค้นหาและกรองข้อมูล (Data Filtering)

ผู้ใช้สามารถเลือกแสดงข้อมูลเฉพาะส่วนที่ต้องการได้ผ่านตัวกรอง ได้แก่

- **ช่วงเวลา:** กำหนดปีและเดือนเริ่มต้น–สิ้นสุด
- **ชื่ออาจารย์:** เลือกดูผลงานของอาจารย์แต่ละคน
- **หลักสูตร:** กรองข้อมูลตามกลุ่มหลักสูตร
- **ฐานข้อมูล (Indexing):** เลือกฐานข้อมูลที่เกี่ยวข้องกับผลงาน เช่น Scopus, TCI หรือ Web of Science

มีปุ่มค้นหาและล้างตัวกรอง เพื่อให้ผู้ใช้สามารถเปลี่ยนเงื่อนไขการแสดงผลได้อย่างสะดวก

### 📊 2. แสดงสถิติสรุป (Dashboard Overview)

เว็บไซต์แสดงข้อมูลสรุปผ่านการ์ดสถิติ 4 ส่วน ได้แก่

| สถิติ | รายละเอียด |
|---|---|
| ผลงานทั้งหมด | จำนวนผลงานทางวิชาการตามเงื่อนไขที่เลือก |
| จำนวนอาจารย์ | จำนวนอาจารย์ที่มีผลงานในชุดข้อมูล |
| ผลงานเฉลี่ยต่อคน | ค่าเฉลี่ยจำนวนผลงานทางวิชาการต่ออาจารย์ |
| ช่วงเวลาที่มีผลงานสูงสุด | ปีหรือเดือนที่มีจำนวนผลงานมากที่สุด |

สถิติจะเปลี่ยนตามตัวกรอง เพื่อให้ผู้ใช้เห็นภาพรวมของข้อมูลที่กำลังวิเคราะห์

### 📈 3. วิเคราะห์ข้อมูลด้วยกราฟ (Data Visualization)

เว็บไซต์นำเสนอข้อมูลด้วยกราฟหลายรูปแบบ ได้แก่

**กราฟผลงานรายปีและรายเดือน**

แสดงจำนวนผลงานทางวิชาการตามช่วงเวลา เพื่อให้เห็นแนวโน้มการตีพิมพ์ และสามารถพิจารณาการเปลี่ยนแปลงของจำนวนผลงานในแต่ละช่วงได้

**กราฟสัดส่วนประเภทผลงาน**

ใช้กราฟโดนัทและกราฟแท่งแบบซ้อน (Stacked Bar Chart) เพื่อแสดงสัดส่วนและเปรียบเทียบจำนวนผลงานในแต่ละประเภท

**กราฟผลงานแยกตามหลักสูตร**

แสดงจำนวนผลงานของแต่ละกลุ่มหลักสูตร ช่วยให้เปรียบเทียบการกระจายตัวของผลงานทางวิชาการได้

**กราฟ Top 10 อาจารย์**

แสดงรายชื่ออาจารย์ 10 อันดับแรกตามจำนวนผลงานที่ตรงกับเงื่อนไขการกรอง โดยใช้กราฟแท่งแนวนอน

กราฟต่าง ๆ มีตัวเลขประกอบ เพื่อช่วยให้ผู้ใช้สามารถอ่านและเปรียบเทียบข้อมูลได้ชัดเจนยิ่งขึ้น

### 🎓 4. วิเคราะห์ข้อมูลตามกลุ่มหลักสูตร

ระบบจัดกลุ่มหลักสูตรหลักสำหรับการวิเคราะห์เป็น 5 กลุ่ม ได้แก่

- **DE**
- **DBiz**
- **AISE**
- **Comp** (รวม MsComp)
- **ไม่ระบุ**

ข้อมูลที่มีชื่อหลักสูตรหลายกลุ่มหรือมีเครื่องหมาย `*` สามารถนำมาพิจารณาภายใต้กลุ่มหลักสูตรที่เกี่ยวข้องได้ โดยยังคงชื่อหลักสูตรเดิมในข้อมูลต้นทาง

ตัวอย่างเช่น ผลงานที่ระบุ `DE, AISE, MsComp*` สามารถปรากฏในการวิเคราะห์ของ DE, AISE และ Comp ได้ โดยนับเป็นหนึ่งผลงานในแต่ละกลุ่มที่เกี่ยวข้อง

### 👨‍🏫 5. เปรียบเทียบผลงานอาจารย์ (Staff Comparison)

ผู้ใช้สามารถเลือกอาจารย์หลายคนเพื่อเปรียบเทียบจำนวนผลงานทางวิชาการได้

ระบบจะแสดงผลเป็นกราฟเปรียบเทียบตามช่วงเวลาที่เลือก ช่วยให้เห็นความแตกต่างของจำนวนผลงานระหว่างอาจารย์แต่ละคนได้อย่างชัดเจน

### 📥 6. ส่งออกข้อมูล (Data Export)

เว็บไซต์รองรับการนำข้อมูลออกไปใช้งานต่อ ได้แก่

- **Export Summary CSV:** ดาวน์โหลดข้อมูลสรุป
- **Export Records CSV:** ดาวน์โหลดรายการผลงานตามตัวกรองที่เลือก
- **Save as PDF:** บันทึกหน้า Dashboard เป็นเอกสาร PDF ผ่านระบบพิมพ์ของเบราว์เซอร์

ฟังก์ชันเหล่านี้ช่วยให้สามารถนำข้อมูลไปประกอบรายงาน การนำเสนอ หรือการวิเคราะห์เพิ่มเติมได้

### 🗂️ 7. จัดการข้อมูลผลงานทางวิชาการ (Data Management)

เว็บไซต์มีหน้าต่าง **จัดการข้อมูล** สำหรับผู้ดูแลระบบ โดยใช้รหัสผู้ดูแลเพื่อควบคุมการดำเนินการกับฐานข้อมูล

ความสามารถประกอบด้วย

- เพิ่มรายการผลงานทางวิชาการทีละรายการ
- นำเข้าข้อมูลหลายรายการผ่านไฟล์ CSV
- ดาวน์โหลดไฟล์ CSV Template สำหรับเตรียมข้อมูล
- ค้นหาและตรวจสอบรายการในระบบ
- แก้ไขข้อมูลรายการที่มีอยู่
- ลบรายการที่ไม่ต้องการ
- สำรองข้อมูลเป็นไฟล์ CSV
- ลบข้อมูลทั้งหมดโดยมีขั้นตอนยืนยันก่อนดำเนินการ

ระบบยังตรวจสอบข้อมูลซ้ำโดยเปรียบเทียบทั้ง 6 คอลัมน์ ได้แก่ `Year`, `Month`, `Staff name`, `Program`, `Type` และ `Indexing` เพื่อช่วยลดการนำเข้ารายการที่เหมือนกัน

> การเพิ่ม แก้ไข และลบข้อมูลใน Google Sheets ต้องมีการตั้งค่าระบบเขียนข้อมูลและสิทธิ์ผู้ดูแลอย่างถูกต้อง

## 🖥️ วิธีใช้งานเว็บไซต์

**1. เข้าสู่เว็บไซต์**

เปิด https://coc-qa-dashboard.vercel.app ผ่านเว็บเบราว์เซอร์

**2. เลือกข้อมูลที่ต้องการวิเคราะห์**

กำหนดช่วงเวลา ชื่ออาจารย์ หลักสูตร หรือฐานข้อมูลตามที่สนใจ แล้วกดค้นหา

**3. ดูผลการวิเคราะห์**

ตรวจสอบจำนวนผลงานจากการ์ดสรุปและกราฟต่าง ๆ เพื่อวิเคราะห์แนวโน้มและเปรียบเทียบข้อมูล

**4. เปรียบเทียบอาจารย์**

เลือกอาจารย์ที่ต้องการเปรียบเทียบ เพื่อดูจำนวนผลงานในรูปแบบกราฟ

**5. ดาวน์โหลดข้อมูล**

เลือกส่งออกข้อมูลเป็น CSV หรือบันทึก Dashboard เป็น PDF เพื่อนำไปใช้งานต่อ

**6. จัดการข้อมูล (สำหรับผู้ดูแล)**

เปิดเมนูจัดการข้อมูล ใส่รหัสผู้ดูแล และเลือกดำเนินการกับข้อมูลตามสิทธิ์ที่ได้รับ

## 🗃️ โครงสร้างข้อมูล

เว็บไซต์ใช้ข้อมูลผลงานทางวิชาการจาก Google Sheets โดยมีคอลัมน์หลักดังนี้

| คอลัมน์ | รายละเอียด |
|---|---|
| `Year` | ปีที่เผยแพร่ผลงาน |
| `Month` | เดือนที่เผยแพร่ผลงาน |
| `Staff name` | ชื่ออาจารย์เจ้าของผลงาน |
| `Program` | หลักสูตรที่เกี่ยวข้อง |
| `Type` | ประเภทผลงานทางวิชาการ |
| `Indexing` | ฐานข้อมูลที่จัดทำดัชนีผลงาน |

ระบบรองรับการแปลงปี พ.ศ. เป็น ค.ศ. และสามารถประมวลผลข้อมูลตามช่วงปีและเดือนที่เลือกได้

## 🏗️ การทำงานของระบบ

เว็บไซต์ใช้สถาปัตยกรรมเว็บแอปพลิเคชันที่เชื่อมต่อระหว่างหน้า Dashboard, Vercel Serverless Functions และ Google Sheets

**การอ่านข้อมูล**

```text
Google Sheets
     ↓
Vercel Serverless Function
     ↓
Data Processing
     ↓
Dashboard & Charts
```

**การจัดการข้อมูล**

```text
ผู้ดูแลระบบ
     ↓
Data Management Interface
     ↓
Vercel API
     ↓
Google Apps Script
     ↓
Google Sheets
```

การแยกส่วนแสดงผลออกจากการเชื่อมต่อข้อมูลช่วยให้สามารถจัดการการตั้งค่าของระบบผ่าน Environment Variables โดยไม่จำเป็นต้องเปิดเผยรหัสหรือ Token ภายในหน้าเว็บไซต์
